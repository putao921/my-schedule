# My Schedule · 桌面日程小工具

按 `主题包/月视图.png` 的像素风视觉重建的日程小工具原型。**单文件网页应用，双击即可运行**，已内置月 / 周 / 列表三种视图与桌面 / 平板 / 手机三档响应式布局。

---

## 一、如何打开

直接双击 `index.html` 即可（Chrome / Edge / Safari 均可，无需安装任何依赖）。

如需在本机起服务（便于手机同局域网访问）：

```bash
cd schedule-widget
python -m http.server 8777
# 浏览器打开 http://127.0.0.1:8777
```

调试参数（附加在网址后）：

| 参数 | 取值 | 说明 |
|---|---|---|
| `view` | `month` / `week` / `list` | 直接打开指定视图 |
| `theme` | `light` / `night` | 指定配色 |
| `date` | `2026-09-23` | 指定基准日期 |

例：`index.html?view=week&theme=night&date=2026-09-23`

## 三、三个视图

**月视图** —— 对应参考图，7 列 × 6 行日期格。当天填充暖橙色，周末粉底，节假日右上角挂缎带角标；格子内用「划线文字」表示已完成日程、淡色横条表示时段块，与参考图一致。底部汇总当月事件与任务数。

**周视图** —— 左侧 00:00–24:00 时间轴，7 个日列。事件按分钟定位成卡片，时间重叠时自动并排分道（`layoutOverlaps`）。属于今天的列高亮，并绘制一条红色「当前时刻」横线，打开时自动滚到当前小时。

**列表视图** —— 左侧按日期分组的事件流水，含搜索框与三个筛选器（范围 / 排序 / 标签）；右侧为任务面板，可勾选完成，逾期显示「Today」。

## 四、多端适配策略

采用**桌面优先、向下收敛**的策略，三档断点：

| 断点 | 形态 | 关键变化 |
|---|---|---|
| `≥1440px` | 大桌面 | 格子加高、侧栏加宽 |
| `1024–1439px` | 常规桌面 | 完整侧栏导航 + 三视图 |
| `768–1023px` | 平板 | 侧栏改为**顶部横向标签**，月格加高，列表任务栏移至下方 |
| `≤767px` | 手机 | 侧栏隐藏，改为**底部标签栏**；工具条横向滚动；周视图时间列收窄至 34px；任务侧栏隐藏 |

设置这些断点的目的是让**同一套 DOM 与组件**在三端复用，未来接 WPF / Electron / Flutter 时可直接对照迁移：

- 导航：桌面侧栏 → 平板顶栏 → 手机底栏，对应移动端的 Tab Bar 范式。
- 触控：手机上按钮最小高度 36px、日期格 52px，符合触控热区建议。
- 安全区：手机版使用 `env(safe-area-inset-*)`，适配刘海屏与手势条。
- 溢出：所有页面在 390 / 834 / 1440 三档下 `scrollWidth == viewport`，无横向滚动。

## 五、功能清单

- 三视图切换（顶部分段控件 / 侧栏 / 底部标签栏均可）
- 新建、编辑、删除日程（标题、类型、日期、起止时间、备注、完成态）
- 点击日期格选中；点击左右月份灰格自动翻月
- 上一页 / 下一页 / 回到今天
- 列表搜索与三重筛选
- 任务勾选完成
- 夜间模式切换
- 键盘快捷键：`M` 月、`W` 周、`L` 列表、`N` 新建、`T` 今天、`←/→` 翻页、`Esc` 关闭

## 六、数据存储

使用浏览器 `localStorage`（键名 `myschedule.v1`），首次打开会写入一批演示数据，之后刷新不会丢失。

> **注意**：`app.js` 中的 `seedData()` 与 `HOLIDAYS` 均为**演示用模拟数据**，不是真实日程，也未接入任何日历服务。若要接真实数据，替换这两处即可 —— 数据结构为：

```js
event = { id, date: 'YYYY-MM-DD', start: 分钟数, end: 分钟数, title, tag, note, done }
task  = { id, text, done, due: 'YYYY-MM-DD' | null, tag }
```

## 七、已验证

用 Chrome 无头模式 + DevTools Protocol 在真实视口下做了渲染与交互回归，证据见 `shots/`：

- 桌面 1440×900、平板 834×1112、手机 390×844 三档截图，含月 / 周 / 列表与夜间主题
- 交互回归：视图切换、搜索、任务勾选、新建日程落库、主题切换、快捷键、日期选中、翻页、当前时刻线 —— **页面错误 0 条**

已知限制：`Pin`（窗口置顶）与 `Settings` / `Profile` 入口为占位，浏览器环境无法实现系统级能力，点了会给出明确提示而非静默；窗口标题栏的最小化 / 最大化 / 关闭按钮同理，仅作视觉还原。
