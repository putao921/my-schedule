## 触屏拖拽修复 + 深色降饱和（提交 3b6635a，SW v9，未发布）
- **触屏拖拽失效真因**：`.wk-ev` 的 `touch-action: pan-y` 让浏览器把竖向手势判给滚动并发 pointercancel，拖拽未起即死；且触屏需长按 260ms 才 begin。改为 `touch-action:none` + 触屏移动 >9px 即起拖（不再 cancel）。周网格仍可从空白 slot 滚动。
- 手柄加高 13px + 可见握把 `.wk-h::after`（currentColor，明暗块都可读）。
- 深色模式：`desaturate(hex, 0.10)`（HSL 降饱和）仅在 theme==='night' 且颜色为 hex 时生效；预设色是 CSS 变量，本就跟随主题，不动。
- **验证手法（可复用）**：headless 合成 PointerEvent 测不出拖拽，改用 CDP（`Input.dispatchMouseEvent` / `dispatchTouchEvent` + `Emulation.setTouchEmulationEnabled`）派发真实事件，Node22 内置 WebSocket 直连，能真验拖动/拉伸是否生效。
- 自测 104/106，week.* 19 项全绿。
