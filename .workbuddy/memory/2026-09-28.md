## 触屏拖拽仍然失效 —— 根因是 Pointer Events 本身（提交 60becb0，SW v10）
- 上一轮（v9）改 `touch-action:none` + 9px 阈值只是缓解：iOS Safari 虽支持 Pointer Events，但一旦它把手势重新判定为滚动/长按选择，会发 `pointercancel`，且此时 `touchmove` 已不再 cancelable → 手指下的拖拽被中断。Chrome 桌面的 CDP 模拟触摸不会复现（所以当时"验证通过"）。
- **修法**：手指一律走 **Touch Events**，Pointer Events 只服务鼠标/触控笔。
  - `onPointerDown/Move/Up` 首行 `if (ev.pointerType === 'touch') return;`；`pointercancel` 对 touch 也直接 return（不再 tear down）。
  - `touchstart`(passive) → `press()`；`touchmove` 中**只要 armed 就立刻 `ev.preventDefault()`**（必须第一帧就 preventDefault，iOS 一旦开始滚动就不再受理）→ `travel()`；`touchend` → `release()`。
  - 内部统一 `press(x,y,target,touch)` / `travel(x,y)` / `release(x,y)` 三个入口，两条传输不漂移；`viaTouch` 决定阈值（触屏 9px / 鼠标 6px）。
  - 鼠标路径加 `setPointerCapture`；`contextmenu` 在 armed/dragging 且落在 `[data-ev]` 上时 preventDefault（安卓长按弹菜单会打断起拖）。
- CSS：`.wk-ev` 加 `-webkit-user-select:none; user-select:none; -webkit-touch-callout:none`（iOS 长按放大镜/选择）；`.view` 加 `overscroll-behavior-y: contain`（拖到边缘不再整页橡皮筋）。
- **测试教训**：新增的 `testTouchDrag` 一开始"ghost 缺失/落点没变"，真因是**测试用的块在视口外**，`elementFromPoint` 返回 null → 自测要先挑一个 rect 在视口内的块（否则 `scrollIntoView`），并把手指 y 夹在 `innerHeight-60` 内。这也是既有 `drag.ghostWithTag/drag.crossDay` 一直失败的同类原因（headless 视口只有 428px 高）。
- 自测 114/116（新增 10 条 `touch.*` 全绿，含 `touch.preventDefault`——断言"浏览器被告知不要滚动"）；CDP 真实触摸复验：整体拖动 8:30→11:30、底部手柄拉伸 12:30→14:15。
- 仍失败的两条 `drag.*` 是鼠标合成 PointerEvent 在 headless 的坐标钳制局限，非回归。

## 真正的根因（用户截图定位）：重复实例拖动静默丢弃（提交 153ed81，SW v12）
- **用户 ?dragdebug=1 截图是破案关键**：`tm pd=true drag` 反复出现 = 拖拽一直在跑、preventDefault 也生效了；故障在**松手落库**。截图里拖的是"法律职业伦理/法理学"——每周重复课程。

- 修复（SW v12，提交 153ed81）：

## 撤销/重做（提交 fdfe1db，SW v13）
- 新增 `js/history.js`（`window.Undo`）：快照式历史（只快照 events+tasks，**不含 settings**，否则撤销误拖会连字号一起回退），栈深 40，内存态（刷新后清空）。
- 记录方式：`Store.onChange` 只认 `/^(event|task)\./`；`'replace'`（云同步/导入）视为外部整批替换 → `reset()` 不进栈。
  - **坑（自测抓到）**：undo/redo 自己通过 `Store.replaceAll` 回放 → 会 emit `'replace'` → 若不在 `suspended` 期间忽略，会把刚 pop 出来的那条历史连栈一起清空（表现为"撤销一次后重做失效""删除后撤销无效"）。修法：监听器首行 `if (suspended) return;`。
  - 另：`base` 必须在模块初始化时就取快照，否则**第一次修改进不了历史**。
- UI：周视图头部 `.cal-hist` 两个圆钮 ↶ / ↷（`calNav(..., {undo:true})`，月视图不传）；禁用态用 `disabled` 而非隐藏；`syncUndoButtons()` 在 render 后 + `Undo.onChange` 回调里刷新（拖拽不一定走 render）。快捷键 Ctrl/Cmd+Z、Ctrl+Shift+Z / Ctrl+Y，输入框内不拦截。
- i18n 新增 `cal.undo/cal.redo/undo.done/redo.done/redo.none`（中英各 5 条）。
- 自测 129/131（新增 9 条 `undo.*`：拖后撤销复原/重做/删除可撤销/按钮状态/设置不被回滚）。CDP 真实路径复验：真实触摸拖动 weekly 课程 → start 480→690 → 点撤销 → 480 且例外消失 → 点重做 → 690。
